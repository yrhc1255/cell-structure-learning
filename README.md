# 微觀細胞研究所

國中七年級自然科「生物體的基本單位與細胞的構造」互動自學網站。

## 課程內容

- 14 個依學習順序編號的獨立網頁
- 細胞發現、形態與功能、動植物細胞構造與顯微觀察
- 隨堂互動、兩次形成性評量、閱讀素養與綜合挑戰
- 形成性評量不設通過門檻，完成後保存分數
- 所有單選、複選與下拉選項會在每次載入時隨機排列
- 動、植物細胞構造可點選並在圖中亮起，附完整功能說明
- 製片觀察提供 6 張逐步教學插圖
- 兩次形成性評量與綜合挑戰分數會寫入 Firebase Firestore
- 手機、平板與桌面版面

## 本機入口

從 `1_home.html` 開始課程。

## 發布

本專案使用 Firebase Hosting 發布，網站根目錄會導向 `1_home.html`。

Firestore 僅接受 `cell_scores` 集合中符合格式的成績寫入，禁止前端讀取、列出或刪除全班資料。綜合挑戰共 6 題，答對 1 題得 1 分。
